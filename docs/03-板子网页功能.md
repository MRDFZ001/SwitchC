# 03 板子网页功能

按从上到下顺序操作：

- 左上角手柄图标：网络设置入口，联网模式 / 离线模式 / 切换 WiFi；分享、投稿、导入分享码、检查更新都和网络状态有关
- 分类模板：决定画在游戏里的哪个区域，不同分类的画布尺寸、遮罩、可绘区域不同，选错位置和大小就不对
- 上传图片：把要画的图放进板子网页，见 04
- 画布预览：最终效果的提前检查，超出画布的部分不会被绘制
- 缩放和上下左右移动：控制大小和位置，调整后重新看预览
- 画笔大小：1x1 / 3x3 / 5x5，必须和游戏内实际画笔大小一致，否则画错
- 绘图方案 / 精度：越快对稳定性和图像简化要求越高，第一次先用推荐方案
- 高级颜色设置：颜色识别、实机校准、相似色处理，普通用户不要乱改
- 开始并上传任务：网页按预览生成绘图路径并上传到主板，上传时不要刷新、断电、重复点击
- 实时数据区域：当前阶段、进度、预计信息、异常提示，卡住先看这里，不要先乱按手柄
- 右下角分享按钮：分享、投稿、导入分享码
- 底部版本号 / 在线更新：点版本号检查固件更新，更新时不要断电
