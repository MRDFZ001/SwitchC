# 05 开始绘图

1. 确认预览：位置、大小、分类都确认好
2. 上传任务：等待任务上传完成
3. 进入游戏画布：确认光标在中心、画笔大小一致
4. 开始绘制：不要碰手柄，不要拔线
5. 等待完成：完成后再拔出主板

## 安全暂停与保存

- 要暂停：用板子网页里的“暂停”，主板会停在安全点、保存进度并松开按键，不要直接拔线
- 没电或要断电前：先点“保存数据”，下次打开板子网页会提示有未完成任务，可以继续
- 原点继续：重新回到画布中心后可选，主板会重新选择画笔和下一段颜色，再从保存进度继续
- 绘图时不要手动操作手柄，也不要让 Switch 进入休眠，中途干扰容易错位、漏画、任务中断
