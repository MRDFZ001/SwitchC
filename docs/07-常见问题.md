# 07 常见问题

- 烧录找不到串口：先换可传数据的数据线；按住 0/BOOT，点 RST 后不要松开 0/BOOT，再连 ESP32-S2 串口
- Mac 烧录：用 Chrome 或 Edge，确保浏览器有串口权限，被拦截时在浏览器设置里允许串口访问
- 手机连 SwitchC 热点提示无互联网：正常，热点只是用来进后台
- 板子插 Switch 没反应：先查 Switch 里“Pro 手柄的有线连接”是否打开，再确认是 ESP32-S2 mini 固件和可用数据线
- 位置不对：确认分类模板、预览是否居中、图片是否超出有效画布、游戏内画笔大小和网页画笔大小是否一致
- 画到一半中断：查 Switch 是否休眠、线是否松动、是否手动操作了手柄；暂停或断电前先用“保存数据”，不要直接拔线
- 颜色和原图不完全一样：游戏内颜色和普通图片本身有差异，用清晰色块图，少用复杂渐变，高级颜色设置不要乱改
